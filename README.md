# 🌊 Sea Port Scenery (FreeGLUT) 🚢

## 📌 Description
The **Sea Port Project** is an interactive OpenGL-based graphical simulation of a bustling sea port. It features animated ships, containers, a lighthouse, and a truck, all within a dynamic day and night cycle. This project was developed as part of a computer graphics course.

## ✨ Features
✅ **Realistic Day & Night Transitions** 🌞🌙  
✅ **Smooth Animation of Ships & Trucks** 🚢🚛  
✅ **Toggleable Lighthouse Light** 💡  
✅ **Interactive Sound Controls** 🔊  
✅ **Start & Stop Dynamic Scenery** 🎬  

---

## 🎮 Controls
| 🎹 Key / 🖱 Mouse Input  | 🎯 Action |
|--------------------|---------------------------|
| 'N' or 'n'       | 🌙 Transition to night       |
| 'D' or 'd'       | 🌞 Transition to day         |
| Space            | ⏸ Stop scenery              |
| 'S' or 's'       | ▶ Start scenery             |
| 'M' or 'm'       | 🔊 Start/stop sound          |
| Hold 'LEFT' Mouse | 💡 Toggle lighthouse light   |
| Esc              | ❌ Exit App                   |

## 🛠️ Installation & Setup  
1. **Ensure you have FreeGLUT installed** on your system.  
2. **Clone this repository**:  
   ```sh  
   git clone https://github.com/Atik471/Sea-Port-freeglut  
   cd Sea-Port-freeglut  
   ```  
3. **Compile the project** using g++:  
   ```sh  
   g++ -o main main.cpp -lfreeglut -lopengl32 -lglu32  
   ```  
4. **Run the executable**:  
   ```sh  
   ./main  
   ```
